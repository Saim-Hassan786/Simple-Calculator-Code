# 🧮 Simple Calculator

A **Simple Calculator** that performs basic arithmetic operations: addition, subtraction, multiplication, and division. This is a beginner-friendly project for understanding how to build interactive CLI applications using programming logic.

---

## 🎯 Features

- ➕ Addition
- ➖ Subtraction
- ✖️ Multiplication
- ➗ Division
- 🚫 Handles division by zero
- 🔁 Allows continuous operations until the user chooses to exit

---

## 🧠 How It Works

1. User is prompted to enter two numbers.
2. User selects the operation to perform.
3. The result is displayed.
4. Option to perform another calculation or exit.

---

## 📦 Technologies Used

- Language: **Python** (or any other language)
- Interface: **Command Line Interface (CLI)**
